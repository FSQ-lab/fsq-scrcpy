# Codex adapter

本目录让 Codex 复用根 `AGENTS.md` 和 `.github/agents/` 定义的 GitHub Issue 驱动协作规则。源角色是职责边界的唯一来源；本目录只负责宿主适配。

## Entry

项目计划、优先级、依赖、状态和验收证据统一记录在 GitHub Issues。开始非平凡工作前读取或创建对应 Issue，补齐目标、非目标、依赖、验收标准和验证入口；行为或接口变化在实现中同步更新适用 SPEC。

主会话承担 Tech Lead，直接分配六个叶角色；最多三个并发，且只对依赖已满足、文件所有权互斥的任务并行。每个角色开工前读取根规则、对应 `.github/agents/<role>.agent.md`、关联 Issue 和适用技术契约。

若当前 Codex 版本无法原生选择自定义角色，可创建新的通用子上下文并要求读取 `.codex/agents/<role>.toml` 和源角色正文。不得声称这种回退已加载原生角色或形成权限隔离。审查按风险安排，不是所有变更的强制门槛。

创建或修改配置不会改变已经启动的聊天；需要时从项目根新开会话验证角色发现。
